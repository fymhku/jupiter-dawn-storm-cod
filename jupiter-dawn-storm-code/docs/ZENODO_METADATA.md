## Description

Analysis and figure-source package associated with the Jupiter dawn-storm
manuscript. Contains processed one-second Juno magnetic-field windows for
2017-05-16 and a quiet crossing on 2017-05-10; magnetic-field decomposition;
calibrated one-sided wavelet power spectral density with mean subtraction,
scale-dependent boundary exclusion and discrete-filter-energy calibration;
archived CWT amplitude maps; 2–5 mHz band-pass analysis; original polynomial
root scripts; numerical validation, provenance and reproduction instructions.

The full PSD frequency grids are retained, including peaks outside the
current 3.5–50 mHz figure display. Original raw-PDS-to-JSS/RTP processing and
HST reduction/map construction are not included. This package does not
claim complete reproduction of every manuscript figure from raw archives.
