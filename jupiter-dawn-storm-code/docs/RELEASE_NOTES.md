## v1.1.0 — Calibrated PSD and 2017 analysis package

- Integrate the wavelet-based one-sided PSD calibration, boundary exclusion,
  numerical validation and full spectra for the 2017-05-16 and 2017-05-10 events.
- Provide the current Fig4 and S3 PSD plotting range (3.5–50 mHz) while
  retaining the full original frequency grids and all local peaks.
- Include processed magnetic-field windows and archived CWT amplitude arrays.
- Add portable workflows, bilingual documentation, provenance and checksums.
- Preserve original theory root scripts; document unsupported raw-PDS/HST steps.

The archived CWT amplitude maps and calibrated PSD are distinct products.
